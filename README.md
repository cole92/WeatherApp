# Weather App (Vanilla JavaScript)

A simple weather app that lets you search for a city and displays the current conditions.

## Features
- City search
- Current temperature (°C) and weather status
- Min / max temperature display
- Background/visual theme (single-page UI)

## Tech stack
- HTML / CSS
- JavaScript (vanilla)
- Weather API (client-side fetch)

## Run locally
```bash
python3 -m http.server 5173
```

Open:
- http://localhost:5173
